Privacy policy

Viagem · last updated 3 October 2026

Who uses Viagem

Viagem is a personal application used by its owner alone, on the owner's own computer. It is not offered to anyone else.

What Viagem accesses in Google

With the owner's consent, Viagem uses one Google permission: read-only access to the owner's Gmail (https://www.googleapis.com/auth/gmail.readonly). It uses that access only when the owner presses a button asking it to check, and then only as follows:

  • It lists messages sent by alerts@seats.aero in the last 30 days.
  • It reads each message's sender, date and subject. It reads a message's body only when the sender is alerts@seats.aero.
  • It never reads other mail, and never sends, deletes, labels, moves or modifies any message.

How the data is used

From each Seats.aero alert email, Viagem reads the flight award availability it announces: route, date, program, cabin, miles, taxes and flight numbers. It files that information beside the owner's saved flight searches. To read the email's text, Viagem sends that text to a language model the owner has an account with (OpenCode Go). The model returns the awards as structured data. No other use is made of Gmail data.

What is stored

Viagem keeps, on the owner's computer only, the awards it read and a short record of each message: its Gmail message id, subject, sender, the time it was sent, and where it was filed. It does not keep email bodies. The Google sign-in token is kept in the owner's operating-system keychain, not by Viagem.

Sharing

Gmail data is not sold, shared with, or transferred to anyone, apart from sending an email's text to the language model as described above, solely to read its flight awards. It is not used for advertising, and it is not used to train models.

Viagem's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke Viagem's access at any time at myaccount.google.com/permissions, and can delete Viagem's local data by deleting its data folder.
